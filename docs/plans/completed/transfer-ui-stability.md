# 文件传输页控件与布局稳定性

状态：实现与本机自动验证完成（2026-10-26）；真实远端和三平台原生交互仍待验收。

检查并修复实际复制提交时 spinner 撑宽按钮、状态消息插入造成双栏位移、刷新时路径/筛选失焦变灰、错误重试闪动与无关任务触发刷新；弹窗统一公共按钮并验证异步宽度、重复提交和错误反馈。保持端点切换清除旧目录与选择的安全边界。

共用控件变动保持默认行为兼容，并运行组件夹具、深浅主题、窄窗口及 AGENTS.md 门禁。原生 WebView 无法精确绑定时，不以安装版代替验收。

## 改动

- 公共 Button 增加显式 `reserveLoadingSpace`，保留标签的自然尺寸，提交中将标签透明并在原按钮内居中显示 spinner，默认不启用。原有图标按钮保持原布局。去掉公共按钮与确认弹窗的 hover 上移，保留主题颜色反馈。
- 复制、确认、新建/重命名和权限提交启用稳定 loading 布局；后两类弹窗迁移公共 Button，并补齐 dialog 标注、输入焦点及非提交态 Esc 关闭。提交仍禁重复操作/关闭。
- 页面反馈复用底部帮助区域，窄窗预留两行，排队结果不插入双栏之前；错误仍可完整换行显示，不隐藏关键反馈。
- 背景刷新不禁用路径和本地筛选，不覆盖未发送的路径输入。端点切换立即更新路径，不显示旧端点目录；新目录仍清除旧选择。重复失败请求保持错误直到结果返回，并刷新实际失败路径。
- 完成事件仅刷新目标端点受影响目录（包含可见的目录子层级），不因其他连接、来源端或其他目录完成任务而刷新。

## 验证

浏览器真实组件/模拟 API 验证深浅主题、760px 窄窗、延迟刷新/复制/重命名/权限提交：控件与弹窗按钮 busy 前中后边界相同、页面反馈不推动列表、输入草稿和筛选保留、重复点击不排队、错误重试不导致表头跳动、端点切换不保留旧路径、无关任务不刷新，以及对话框 Esc 行为。新增目的端刷新规则单测。

通过 typecheck、lint、Prettier、renderer 239 项、Rust 单元 903 项、CLI 10 项、contract 23 项、Clippy all-targets/all-features 与 CSS contract（既有 11 条 !important 和 6 处 legacy 颜色提示未增加）。首轮 renderer 全量曾出现一次无断言详情的 terminal-ui-state 测试进程失败，独立重跑和全量复跑均通过，未修改终端实现。

## 退出弹窗宽度回归

发现首版对称 spinner 留白把所有确认按钮额外撑宽 32px，影响了退出确认。改为沿用自然内边距及标签布局，加载时透明保留标签占位并在按钮中心覆盖 spinner；可访问名称、禁用重复提交和尺寸稳定性继续保留。深浅主题回归额外验证“直接退出”与“取消”保持相同标准宽度、启用加载布局与普通按钮自然宽度相同、busy 前中后位置/尺寸一致以及 spinner 居中。
