# 文件传输安全加固

状态：实现与本机自动验证完成（2026-10-26）；真实远端与三平台原生验收待完成。Refs #354；不代表发布验收。

按顺序修复：

1. 跨端严格提交：拒绝符号链接与直接截断，失败保留旧文件及断点；原上传下载默认语义不变。
2. 文件传输页显式传递 skip/replace，任务持久化策略，提交时重新检查；包含目录逐文件策略。
3. 绑定实际 worker 使用的已解析端点；配置编辑不改写活跃会话身份；恢复/清理校验真实身份。
4. 同一会话参与的跨端任务统一排队，获取队列时可取消；避免双向锁等待。

回归覆盖提交失败/属主差异/符号链接、缓存过期与提交时冲突、旧任务默认兼容、配置变化和重连、双向并发与排队取消。运行 AGENTS.md 全部门禁；真实远端及原生三平台未验证项如实记录。

## 实现与验证结果

四项按计划完成。严格远端提交与不带策略的旧上传下载路径隔离；显式策略任务的单文件/目录逐文件先检查实际目标，提交时复查。任务持久化策略并使用独立断点；含策略时使用 journal v2。端点身份来自连接建立时实际使用的已解析路由，编辑存储配置不会改写活跃会话身份。相同 profile 参与的复制固定顺序排队，等待可取消，无关端点仍可并行。

回归覆盖真实本机 OpenSSH、内存 SFTP 属主差异协议夹具和 FTP 重命名故障夹具，以及本地提交、旧任务兼容、端点重连、排队取消和浏览器双向策略参数。门禁通过：typecheck、lint、Prettier、renderer 238 项、Rust 单元 902 项、CLI 10 项、contract 23 项、Clippy all-targets/all-features、浏览器夹具及 CSS contract（既有 11 条 !important 和 6 处 legacy 颜色提示，无新增）。

兼容边界：旧开发版跨端任务仅记录可编辑配置，无法证明实际会话身份，拒绝恢复并保留断点；原上传下载旧任务继续兼容。本地文件系统不支持硬链接时 skip 安全报错并保留断点，不降级覆盖。FTP 的最终检查与 RNTO 之间无法获得跨客户端的原子“不覆盖”保证。详见 [回归记录](../../quality/remote-to-remote-transfer.md)。
