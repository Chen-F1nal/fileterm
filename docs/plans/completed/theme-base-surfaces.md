# 基础颜色补充与灰阶统一

- 基础颜色增加侧栏与工具栏、输入框与按钮、自绘菜单三个入口，沿用 ThemeColorField 和现有主题保存流程。
- core 与 Rust 主题字段同步；旧自定义主题缺少新字段时保留原来的派生配色，深浅色切换和导入导出包含新字段。
- 界面表面颜色和高级 UI overrides 的旧 #2A2A2A / #2E2E2E 迁移为 #303030；四个内置主题、预览和运行时映射保持一致。
- 核对打包主题预设及语义变量链路；不改终端 ANSI 配色、版本和发布记录。

验证：类型、lint、格式、CSS contract、renderer 与 Rust 测试、clippy；浏览器核对菜单背景和新颜色映射。原生桌面效果待用户确认。

## 完成与验证

- 基础颜色已增加三个编辑项，Rust/core 保存字段与归一化一致；高级 UI 覆盖颜色和旧表面灰阶一并迁移。
- 已扫描四个内置主题与全部打包 token 预设；除迁移判断外，界面配色定义中不再保留两种旧灰阶。
- 类型、lint、Prettier、CSS contract、63 项 renderer 测试、754 项 Rust/contract 测试、clippy 通过。
- 浏览器覆盖四个内置主题的新字段映射、自绘菜单实际底色、旧字段缺失时的深浅色切换与灰阶迁移；验证使用模拟 IPC。
- 未确认原生桌面实机效果；未提交或发布。
