# 日志分类开关与终端字重

用户反馈 SSH 消息过多、性能日志易被轮转挤出，以及 WebGL 字体偏细。
截图最后已撤回“终端与界面共用缩放”的判断，不据此改写现有缩放链路。

## 范围

- 复用 UI preferences、bridge、设置公共控件与日志分类，增加详细诊断记录开关。
- 依据用户确认的同类软件调研结论，十四类详情全部默认关闭；默认保留启动退出、连接/重连结果、基础运行 INFO 与 WARN/ERROR。旧默认组合按版本 2 迁移，自定义组合及迁移后的手动选择保留。
- 统一过滤业务 facade 和原生 tracing/log 事件，保留既有脱敏、队列和轮转。
- 增加终端字重 400/500/600，默认保持 400；持久化、跨窗口同步并刷新已有终端网格。
- 不改变全局 UI 字体、终端字号、WebGL 整数栅格或会话 transcript 开关。

## 验证

已通过类型、lint、格式、Rust/contract（850 个单元测试、10 个 CLI、23 个 contract 测试）、
严格 clippy 与 CSS contract；renderer 全量 183 项通过。
浏览器夹具通过 14 类默认值、局部保存、写入失败保留原值、跨窗口事件更新及中英文、深浅主题的紧凑 3/2/1 列响应式布局；说明分层、短名称及常规字重避免拥挤与截断。
分类默认值/严重级别保留、旧配置兼容、字重边界与字重切换后字体加载均有回归测试。
字体粗细最终仍需反馈者在原设备确认。
