# SSH 登录补全与密码显示

## 目标与范围

- 修正密码显示按钮仅限编辑模式的问题，新建与编辑连接、SSH 登录补全均提供显示/隐藏当前输入的密码。
- SSH 缺少登录凭据时可显式选择密码或密钥库中的私钥，支持复用现有导入和私钥口令交互。
- 登录弹窗复用 root 访问窗口的标题栏、常规/认证分组、底部按钮栏和主题样式。
- 已保存凭据仍不进入公开 profile、snapshot 或日志；补全认证只作用于本次连接，不修改已保存连接。

## 影响链路

`packages/core` 交互类型 → renderer 登录弹窗与 SSH 交互 hook → 既有 Tauri SSH 交互响应 → Rust SSH transport → 既有密钥认证服务。
