# 文件区域左侧显示模式

- 默认继续使用本地文件列表；文件工具栏提供本地文件 / 远程目录树切换，通过现有 ui-state IPC 持久化。
- 远程目录树以文件通道的根目录为起点，按需读取目录并缓存；当前路径变化时展开祖先并定位当前目录。
- 读取树节点使用独立只读 IPC，复用带超时与取消的协议 worker，不修改 workspace.remotePath / remoteFiles。
- 点击树节点沿用已有远程导航；保留右侧列表的上传、下载、权限模式、筛选与跟随终端入口。
- 新组件消费主题语义 token，复用 DropdownSelect / VerticalScrollbar，支持键盘导航和节点错误重试。

验收：类型、静态与格式检查、renderer/Rust 测试、clippy、CSS contract；验证默认模式、切换持久化、懒加载、路径联动、会话与权限隔离、错误重试和键盘导航。

## 完成结果

- 已实现两种布局及持久化；目录树按需读取，错误可重试，支持键盘导航、当前目录定位与会话/权限模式隔离。
- 目录树模式共享路径与筛选栏，标题和首行对齐，树节点与右侧文件列表均为 24px；浏览器检查覆盖 720px/1100px 宽度、三平台控件与四种内置主题。
- 类型、lint、Prettier、renderer 测试（63 项）、Rust/contract 测试（753 项）、clippy、CSS contract 和 renderer 构建通过。
- 浏览器使用实际组件与模拟 IPC；尚未进行真实 SSH/FTP 连接和原生桌面端操作验证。
