# 标签切换时保持侧栏宽度

- 当前改动先提交为 `d663534a`，本次只修复侧栏宽度和终端右侧边框过渡。
- 根因：主页对保存宽度施加视口上限，普通连接页直接读取保存宽度；右侧 12px 装饰边框条件挂载且没有动画。
- 统一普通布局下主页与会话页的实际展开宽度及拖拽上限，保留保存宽度与主机分组的独立侧栏。
- 右侧边框常驻，用宽度和透明度过渡控制显隐，遵守减少动态效果设置。
- 验证：增加切换宽度及边框过渡回归检查，运行项目质量门禁；桌面验证只绑定当前项目开发进程。
