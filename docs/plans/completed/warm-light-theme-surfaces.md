# 暖色浅色主题层次

- Solarized 和 Gruvbox 的终端保留原有暖色，侧栏、列表、输入框、菜单与浮层使用不同深浅的米色。
- 修正主题预设读取 color-mix/rgb 时被十六进制验证回退成纯白的问题；颜色转换为可保存的十六进制值。
- 未修改的打包预设在设置打开后更新到当前 token 颜色，自定义主题保留用户配色。
- 同步预览和编辑器底色，检查文本对比度、主题设置与保存值一致性。

## 完成结果

- Solarized 和 Gruvbox 已使用米色层次，并同步输入框、菜单、预览和编辑器底色。
- 列表空白区域与数据行、目录树统一背景，避免短列表出现亮色矩形。
- 修正所有打包预设的混合色读取；未修改预设在设置中刷新配色，自定义配置不覆盖。
- 类型、lint、格式、CSS contract、63 项 renderer 测试通过；浏览器用例已覆盖所有打包预设深浅色及设置用背景字段。
- 当前环境缺少 Playwright，浏览器用例未运行；也未确认原生桌面效果。

- 所有主题的标题栏左侧品牌区与主侧栏使用同一表面颜色；保留现有 macOS Codex 玻璃与失焦处理，浏览器检查两块背景一致。
