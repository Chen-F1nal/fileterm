# 串口稳定性与连接摘要补齐

> 状态：实现完成（2026-10-15）
> 范围：串口普通收发并发、设备打开生命周期、连接摘要与搜索。

## 实现

- 普通发送等待期间继续轮询接收，并复用同一流式解码器、日志和终端输出路径。复用现有
  有界 worker 命令队列，不新增独立发送队列。文件传输及线路控制仍按现有命令顺序执行，
  文件传输期间独占协议流，保留 RS-485、写入/flush 超时和取消行为。
- 连接及测试连接共用设备打开 helper：在 blocking worker 中打开端口，等待最多 15 秒，
  支持取消；尚未开始的任务可终止，已经进入驱动的任务在返回后回收迟到句柄，并应用
  配置的关闭线路状态。打开成功后由原有 session 接管句柄及完整关闭流程。
- 连接列表和首页卡片共用串口摘要：设备路径、波特率和帧格式，例如
  `COM3 · 115200 baud · 8N1`；mark/space 显示 `M/S`。连接搜索包含该摘要。

## 落点

- `sessions/serial/duplex.rs`：发送等待期间接收与取消。
- `sessions/serial/open.rs`：阻塞打开、超时、取消与迟到句柄生命周期。
- `sessions/serial/worker.rs`、`device.rs`：复用既有解码、日志、重连与关闭流程。
- `renderer/app/connection-profile-summary.ts`：统一连接摘要。
- 连接管理器和首页卡片：展示及搜索。

## 验收

- 普通发送被流控或发送延迟阻塞时，接收仍可被处理；取消不等待对端消费发送数据。
- 发送期间 EOF 能结束连接，不能等待整段写入超时。
- 打开超时或取消立即返回；迟到结果仅回收一次；预先取消的任务不访问设备。
- 字符编码跨读取批次保留状态，串口传输仍使用独占的读写流。
- 串口摘要覆盖五种 parity 和旧字段默认值；网络摘要保持其协议字段语义。
- 运行类型、lint、格式、renderer、Rust/contract、Clippy 和 CSS contract 门禁。

## 验证结果

本机类型、lint、renderer（69 项）、完整 Rust/contract（767 项）、Clippy 及 CSS contract
已通过。本次源码和文档格式检查通过。Linux 原生 PTY 测试入口已改为调用共用设备打开
helper，本机未运行 Linux 专属测试。测试不替代实体设备的线路和驱动验收。

## 实体验收边界

原生驱动调用开始后无法通过 async 超时强行终止；迟到端口在调用返回后释放。
Windows/macOS 的异常驱动、占用、拔插、DTR/RTS、Break 和 RS-485 仍需实体设备验证。
Linux PTY 回归用于基本打开和异步收发，不能代替电气线路及实体协议互操作验收。
