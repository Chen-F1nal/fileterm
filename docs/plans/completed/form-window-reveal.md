# 编辑窗口首次显示与重复打开

## 问题

代理列表单击打开导致双击发出两次请求，已有表单被再次导航。独立窗口在工作区快照返回后立即显示，代理/隧道配置和表单首帧尚未就绪，出现加载壳与闪烁。

## 实现

- 代理/隧道行统一双击或 Enter 打开；命令、代理/隧道打开请求使用同步 guard。
- 复用主窗口的双帧显窗逻辑；独立表单等待对应数据加载完成，保留隐藏 WebView 的超时回退。
- 已有原生表单请求相同 URL 时仅聚焦；切换目标时隐藏并导航，由新 renderer 就绪后显示。导航失败恢复原窗口。

## 验证

- 已通过：双击仅打开一次、打开请求防重入、代理数据加载等待；显窗调度覆盖未就绪、双帧提交、取消与超时回退，共 6 项专项回归。
- 类型、lint、全范围 Prettier、120 项 renderer 测试通过。显窗实现抽取到 hook 后更新 contract 路径，Rust 全量门禁重跑通过（776 项单元测试、10 项集成测试、23 项 contract）；Clippy 通过。
- CSS 合约通过，保留已有 11 处 `!important` 警告。
- macOS 当前源码进程为 `target/debug/fileterm`，Vite 5188。Computer Use 不能精确绑定未打包进程，按名称会启动旧打包版；已清理误启动实例，未把它们用于效果验收。macOS/Windows/Linux 原生窗口视觉效果待实测。
- 旧 beta.7 `FileTerm Dev.app` 已取消 Launch Services 注册并移入废纸篓，配置和日志保留；开发进程识别与禁止按名称探测的规则已写入 `AGENTS.md` 和预览文档。
