# 文件传输双栏完整右键菜单

状态：实现与本机自动验证完成（2026-10-26）；原生三平台与真实远端仍待验收。

## 范围与实现

- 复用 `FileContextMenu` 的完整分组、语义颜色与禁用状态，额外保留“复制到另一侧”。本地与远端、文件与目录、多选与空白区域分别设置能力。
- 复用 `createFileOperationsActions` 与既有新建/重命名、删除确认、权限弹窗；删除与快速删除均要求确认。共享处理器仅收窄输入类型，原文件管理器行为不变。
- 两栏共享复制/剪切状态，同端点粘贴复用重名分配及原 copy/move API；跨端复制继续进入确认与持久化传输任务，禁止跨端剪切粘贴。剪切行显示已有淡化样式。
- 打开文件沿用编辑器及远程二进制/大小限制；收藏绑定当前端点 profile；上传/下载复用选择器并显式传递冲突策略。
- 命令绑定当前栏端点，不依赖原会话活动标签；端点变化重建菜单/弹窗状态，提交期间禁用端点切换。浏览、刷新两栏使用独立浏览 API，不改变原会话目录。
- 远端修改仅刷新仍在显示的原会话目录，异步刷新期间切换目录也不覆盖新列表；操作返回的 workspace snapshot 接回统一状态更新。
- 修复修饰键多选被 pointer-drag 起始处理清空的问题，保留多选右键操作。

## 回归

浏览器真实组件/模拟 API 验证完整菜单、空白区域禁用、多选重命名禁用、路径/收藏/打开/重命名/新建绑定端点、删除取消无操作与多选删除确认、同端复制重名、跨端剪切禁用与剪切行样式、权限、选择器上传下载及冲突策略；保存深浅主题菜单截图检查布局。

Rust 回归验证独立目录修改及刷新期间切换目录时原会话列表不被替换。真实服务器与原生三平台交互仍未验收。

## 刷新控件稳定性

刷新不再复用复制提交的 busy 状态；同目录刷新保留列表/选择，仅在结果中移除已不存在的选中路径。复制按钮通过 `aria-disabled` 和提交守卫阻止刷新期间操作，保持已有外观；策略下拉不因目录刷新禁用，刷新按钮在固定图标槽显示 spinner。刷新另一栏不切换活动来源与复制方向。

新增延迟刷新回归断言控件前/中/后的尺寸、颜色、透明度、选择、方向与 spinner 状态；强制触发点击也不会排队，刷新后删除的文件不能继续复制。完整菜单与刷新回归、typecheck、lint、Prettier、renderer 238 项、Rust 单元 903 项、CLI 10 项、contract 23 项、Clippy 和 CSS contract 均通过；CSS 的既有 11 条 !important 与 6 处 legacy 颜色提示未增加。
