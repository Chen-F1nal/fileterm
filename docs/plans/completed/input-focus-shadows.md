# 全局输入与下拉框聚焦阴影

状态：实现与本机自动验证完成（2026-10-26）；原生 WebView 与真实系统菜单待验收。

先按用户要求提交既有工作为 e2640329，再统一输入/下拉框及命令编辑区的聚焦反馈：取消新增彩色描边，使用加深的中性 inset 内环与外阴影。保持所有既有 hover 声明原样，特别是文件工具栏的本地文件、跟随终端、SFTP 悬停蓝框。按钮/单选/复选/滚动条的键盘焦点、错误校验和原生平台菜单行为保持既有语义。

按公共 Input、DropdownSelect、复合输入外壳和遗留页面规则追踪；所有颜色经主题 ref → semantic → 控件消费，覆盖四个主题及自定义主题运行时映射。命令文本区只由外壳显示一次焦点阴影，内部 textarea 不重复加环。

验证：CSS AST 对比基线，确保 hover 声明及非输入控件焦点不变；真实组件浏览器夹具覆盖文本/密码/数字/textarea、下拉、原生 select 壳、复合输入和命令编辑区的鼠标/键盘聚焦、中英文主题/自定义强调色与禁用/错误状态。更新公共组件 skill 与设计约束；运行项目门禁。

深色主题不绘制外部深色阴影层，仅保留中性 inset 内环；亮色主题使用内环与外阴影。终端底部命令输入栏（`terminal-dock-input-shell`）保持原样，不参与本轮聚焦样式统一。

路径栏/筛选框等紧凑透明控件聚焦时只使用既有 1px 中性边框，不叠加 inset 实线或外阴影，防止变成 2px 粗边或出现外层白边。聚焦时指针移入/移出粗细与颜色一致；非聚焦 hover 保持原样。

## 本轮实际调整

- 原有 hover 声明以 CSS AST 与提交 e2640329 对比，包含文件工具栏蓝框；非输入按钮、选择控件和错误状态的实际焦点样式与基线对比。
- 连接、代理、设置、AI、主题控件等聚焦样式迁移至同一语义阴影。深色外部阴影为透明；路径/筛选与运行时隧道仅一层 1px 边框，鼠标停留/移开不改变粗细。
- 终端命令栏、Monaco 与 xterm 内部输入排除统一重置；命令预览恢复包含行号的结构外框，文本区无第二圈。运行时隧道输入使用连接表单字号 token。
- forced-colors 下保留系统键盘描边回退：增加一条已在 skill 说明的平台兼容 !important，普通主题不使用该回退。

## 最终验收结果

- 四个内置主题与两个自定义主题通过实际浏览器验证。路径/筛选、运行时隧道聚焦后的悬停和移开状态均为 1px、无额外 shadow，颜色不跳变；隧道字号与连接表单 token 一致。
- 命令预览的结构边框包含行号列，左侧在数字外侧并与上下边框连通，内部 textarea 不再绘制第二圈。深色主题无外部深色层，终端底部命令栏与提交前基线一致。
- Hover CSS AST 与 HEAD 基线完全一致；实际控件的 hover 边框/背景/阴影和非输入焦点与基线对比通过。下拉框展开态、原生 select 外壳、选择行为、错误状态及高对比度键盘回退通过。
- 输入聚焦夹具、跨页面弹窗夹具、传输页夹具均通过。typecheck、lint、Prettier、renderer 239、Rust 903、CLI 10、contract 23、Clippy 通过；git diff --check 通过。
- CSS contract 通过：canonical !important 从 11 增至 12，仅新增 forced-colors 系统焦点回退一处，已在 skill 明确记录用途；legacy 颜色提示仍为 6 处。
