# 单个 SSH 连接的低占用模式

## 目标与边界

在新建/编辑连接的 SSH「常规」区域提供低占用模式，适配低内存或响应较慢的主机。只修改当前连接表单，不改变全局默认值或其他已保存连接。

## 实施（已完成）

- 开启时关闭资源监控、后台 Exec 和 SFTP，连接超时至少设为 60 秒，保留已有更长超时。
- 按实际选项推导按钮状态，不新增模式标记或存储格式。手动开启上述任一功能或将超时调低后，按钮立即变为未启用；保存后重新打开仍可正确识别。
- 点击关闭时恢复全局默认的监控/Exec 开关、启用 SFTP，并恢复 30 秒连接超时；不恢复开启前的自定义组合，界面明确说明。
- 使用公共 SelectionControl 和高级选项的标签样式，左侧标签与表单对齐，右侧为开关和简短说明；详细规则通过 details 折叠，以本地信息图标替代原生三角，保留键盘和辅助技术语义，提供中英文文案。FTP、Telnet、Serial 和网络设备不显示该模式。
- 常规表单的文本输入框皮肤排除公共 SelectionControl，避免覆盖选中边框、背景和聚焦状态；不在业务 CSS 中复制圆点皮肤。
- 复用已有 profile 字段、保存与连接链路；终端启动遵循连接超时的改动见 [慢 SSH 启动兼容](./slow-ssh-shell-startup.md)。

## 验证

类型检查、lint、Prettier 和 50 项 renderer 测试通过；三项新增测试覆盖预设应用、手动覆盖、序列化后的状态、关闭行为与协议边界。CSS contract 与修改前一致，无新增债务。

以当前源码的 ConnectionModal 浏览器夹具验证四个内置主题、自定义主按钮颜色、模式开关、逐项手动开启、调低超时、保存回调数据与重载状态、协议显示边界。Rust 改动已在上一阶段通过 718 项单元测试、10 项 CLI 测试、23 项 contract 测试及全 targets/features Clippy，本阶段未改 Rust。

样式调整后再次比较四主题下低占用开关与资源监控开关的 computed styles：尺寸、选中边框/背景、中心圆点、文字字号/字重/颜色，以及 hover/focus 状态一致；信息入口的键盘展开通过。

未验证原生桌面 WebView、三平台实机、真实 N1 内存压力或磁盘持久化后的重启。此模式不能修复远端 OOM 或 SSH 服务退出；认证仍使用独立的 30 秒预算。
