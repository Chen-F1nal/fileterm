# 窗口分辨率、HiDPI 与缩放验收

Refs #333。

## 自动回归覆盖

测试位于 `apps/tauri/src-tauri/src/lib/window_geometry.rs`，直接调用生产尺寸与定位函数。输入为 Tauri 提供的物理工作区与 `scale_factor`，不是按操作系统名称分别模拟一遍相同计算。

| 维度                   | 已覆盖的计算输入                                                      |
| ---------------------- | --------------------------------------------------------------------- |
| 低分辨率               | 1280×720、1366×768                                                    |
| 1080p 与 2K            | 1920×1080、2048×1080、2560×1440                                       |
| 16:10 与 Retina 类尺寸 | 2560×1600、2880×1800、3024×1964、3456×2234                            |
| 4K、5K                 | 3840×2160、5120×2880                                                  |
| 超宽与竖屏             | 3440×1440、1080×1920                                                  |
| 缩放因子               | 100%、125%、150%、175%、200%、225%、250%、300%、400%                  |
| 工作区夹具             | 无占用、底部任务栏、左侧任务栏、顶部菜单和底部 Dock、上下双面板       |
| 窗口                   | 主窗口默认尺寸、独立编辑器、连接窗口、保存的 3000×1800 大窗口         |
| 定位                   | 原点屏、负坐标屏、右上方屏；包含工作区偏移与 24×48 逻辑像素的外框余量 |

矩阵包含 2340 个尺寸组合、7020 个定位组合。断言覆盖尺寸为正、原生最小尺寸不阻止适配、窗口含外框余量后不越出工作区，以及负坐标的定位边界。另保留默认逻辑尺寸不被 DPI 重复缩放的定向断言。

本轮 7 项窗口回归、776 项 Rust 单元、10 项 CLI、23 项 contract、全目标 Clippy 和改动格式检查通过。

这些测试只验证几何计算。极高缩放叠加低分辨率时，即使原生窗口边界能放入屏幕，也不代表内部控件、文字与弹窗仍有足够空间。

## 原生平台验收状态

| 平台          | 待验证行为                                                          | 状态               |
| ------------- | ------------------------------------------------------------------- | ------------------ |
| Windows       | 任务栏四边位置、原生边框、系统缩放、混合 DPI 双屏                   | 未完成原生 UI 实测 |
| macOS         | Retina 1×/2×、系统“看起来像”显示模式、菜单栏和 Dock、traffic lights | 未完成原生 UI 实测 |
| Linux X11     | GTK 上报的缩放与工作区、桌面面板、原生窗口尺寸                      | 未完成原生 UI 实测 |
| Linux Wayland | 合成器和 GTK 的分数缩放、工作区上报、窗口定位限制                   | 未完成原生 UI 实测 |

显示器的面板分辨率不一定等于窗口后端上报的坐标空间，尤其是 macOS 显示模式和 Linux 分数缩放。自动测试不能确认后端是否如预期上报这些数据；Linux 工作区无效时回退显示器范围，也不能据此保证面板避让。

原生验收应覆盖首次启动、记住尺寸开关、保存大窗口后换小屏重启、最大化恢复，以及主窗口和独立窗口。运行中改变系统缩放或跨屏拖动尚未有主动重新适配逻辑，需要单独验收。应用内“界面缩放”通过 WebView zoom 控制，与系统 DPI 是不同链路，本矩阵不验证内部布局的界面缩放效果。

桌面 UI 实测须遵守 [开发版识别与预览](desktop-ui-preview.md)，不得操作身份不明的安装版。

## 运行

cargo test --manifest-path apps/tauri/src-tauri/Cargo.toml --locked --lib window_geometry_tests -- --test-threads=1
