# 跨服务器文件传输回归

Refs [Issue #354](https://github.com/St0ff3l/fileterm/issues/354)。本机验证日期：2026-10-25。

## 交互与边界

- 标签栏和文件工具栏的“文件传输”打开独立全高双栏；左侧首次带入当前连接，右侧默认本地。两栏可以选择已连接的 SSH/SFTP 或 FTP/FTPS 会话，路径浏览不改变会话当前目录。
- 工具栏复用紧凑公共控件，按钮、刷新和下拉框统一 28px；正文使用 UI 字体，文件名用 UI 字体，路径/数值保留等宽。顶部/底部空白取消活动面板蓝色描边与文件选择，点击控件不清除选择。双栏间隔 8px，两侧相同的 12px 边栏与内容各留出 12px 空白；表头独立于纵向滚动区域，横向滚动与列宽调整仍保持对齐。入口使用上下排列、方向相反的左右箭头。
- 支持按钮、右键、拖拽复制；目录双击进入，路径栏可编辑，支持筛选、Ctrl/Cmd 多选、Shift 范围选择、方向键和 Enter。普通文件面板可跨标签复制粘贴，跨端剪切始终拒绝。
- 默认同名跳过；覆盖必须显式选择并通过确认框。服务器间目录按文件合并，不删除目标额外文件。包含符号链接的目录在扫描阶段失败，不静默遗漏文件。
- 服务器间数据经过本机内存管道，使用固定大小缓冲和背压；完整内容不会落入 renderer 或本机临时文件。提交前回读 SHA-256，校验会额外消耗两端读取流量。
- 只支持普通用户文件模式；两端需要保持连接。root 模式、同一配置或可识别的相同端点被拒绝。无文件通道能力的 SSH 会话会显示目录错误。
- 暂停、断线或退出保留任务拥有的唯一临时文件。继续前检查两端连接身份、源长度/时间、源和目标临时前缀 hash；不一致时保留断点并拒绝追加。
- 丢弃只删除任务断点；目标配置变更或不在原用户模式时拒绝清理，保留待清理状态。强制丢弃仍使用现有确认流程。
- 复制任务相关目标路径与未完成复制/上传任务互斥，避免同时提交同一目标。含复制任务时 journal 使用 v2，旧版拒绝读取；不含复制任务时继续使用 v1，新版兼容 v1。

## 已有自动验证

- Rust `relay_io`：固定长度、源提前结束、取消和写入背压。
- 真实本机 OpenSSH/SFTP：大于缓冲大小的二进制数据、偏移读取、续传和符号链接目标拒绝。
- 本机 FTP：二进制上传、APPE 续传、REST 偏移读取和前缀读取。
- 本机显式/隐式 FTPS：真实 TLS 控制/数据通道上的中转读写。
- transfer service：源/目标 journal 序列化、旧 journal 导入、目标任务互斥、原有传输/取消/清理回归。
- renderer：两端任务可见性、标签存储恢复、跨标签复制与剪切拒绝；原有 renderer 全量回归。
- 浏览器组件夹具使用真实组件与模拟 API 验证目标选择、复制确认和参数、深浅主题，以及窄窗口的横向边界。模拟 API 不代表原生 IPC 或真实服务器端到端验收。

可重复运行的夹具位于 `apps/tauri/tests/browser/file-transfer.mjs`，复用现有 `PLAYWRIGHT_MODULE_PATH` / `PLAYWRIGHT_CHANNEL` 环境；设置 `FILETERM_UI_ARTIFACT_DIR` 可保存深浅色截图。回归额外断言控件实际高度/字号、点击顶部和底部空白清除选中，以及错误目标目录阻止复制。长列表检查表头位于滚动容器外、上下无空隙，分数像素滚动与横向滚动保持列对齐。

## 原生与真实服务验收

按 [开发版识别与预览](./desktop-ui-preview.md) 核对进程路径、工作目录和 Vite 端口。当前 Computer Use 无法精确绑定 macOS 未打包开发进程，未以安装版替代验证。

在专用测试目录执行：

1. 打开两台服务器，在双栏选择不同连接；确认浏览不修改终端文件区目录。复制零字节文件、带空格/CJK 名称、大文件、空目录和多层目录，逐文件核对 SHA-256。
2. 分别测试 SFTP ↔ SFTP、SFTP ↔ FTP/FTPS、FTP ↔ FTP/FTPS，以及显式/隐式 FTPS。真实证书与代理/跳板保持原连接策略。
3. 准备同名文件，核对默认跳过和显式覆盖；传输期间修改目标应失败并保留断点。目录目标中的额外文件应保留。
4. 暂停并继续；分别断开源端、目标端；退出应用后重启并连接两端，手动继续。篡改断点前缀应拒绝恢复。
5. 覆盖目标只读、空间不足、源文件变化、目录包含符号链接和目标被链接替换；确认源和原目标不因失败被删除。
6. 断点待清理时更改目标配置或切换 root，确认拒绝清理错误目标；恢复原连接后可清理。
7. Windows/macOS/Linux 分别检查键盘、拖拽、滚动、不同缩放和标签切换；本地路径额外检查 Windows 盘符、UNC/网络共享。

仍待完成：以上真实远端组合、三平台原生交互和用户环境确认。源文件在复制期间必须保持稳定；长度/时间检查不能提供文件系统原子快照，目录也不是整体原子事务。
